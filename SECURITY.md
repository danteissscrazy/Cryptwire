# Seguridad

## Avisar de un fallo de seguridad

Si encuentras un fallo de seguridad en Cryptwire, avisa en privado, no en un issue público: en GitHub,
pestaña **Security › Report a vulnerability** ([enlace directo](https://github.com/danteissscrazy/Cryptwire/security/advisories/new)). Cuenta qué
versión usas, cómo se reproduce y qué permite hacer. Se responde por el mismo aviso y, cuando haya arreglo,
se publica con la versión que lo corrige y con tu nombre si quieres.

Solo se arregla la última versión publicada.

## Qué se considera un fallo de seguridad

- Que una web o un marco dentro de WhatsApp Web pueda hacer algo en tu PC a través de Cryptwire: abrir
  programas, leer o escribir ficheros, saltarse los permisos o el filtro de descargas.
- Que Cryptwire mande datos tuyos a cualquier sitio que no sea WhatsApp.
- Que otro usuario o programa del PC pueda cambiar lo que ejecuta Cryptwire o leer tu sesión a través de ella.
- Que el instalador o lo publicado lleve algo que no sale del código del repo.

Los fallos de WhatsApp Web o de Microsoft Edge WebView2 son de WhatsApp y de Microsoft: avísales a ellos.

## In English

Please report security issues privately through GitHub's **Security › Report a vulnerability**
([direct link](https://github.com/danteissscrazy/Cryptwire/security/advisories/new)), not in a public issue. Only the latest release is supported.
